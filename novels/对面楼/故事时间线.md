# 《对面楼》故事时间线

## 一、初遇期（数月前至初识）

- **数月前：** 女作家与母亲闹翻（母亲嫌她写作、要她做出版人），离家搬入小户型公寓，深居写作。
- **某日：** 战争博物馆取材 → 公车事件 → 初识交警 → 交警送归，发现她就住在对面楼。
- **交警值夜班期间（数周至数月）：** 深夜烧烤档多次偶遇（她每回吃烤鸡翅），并肩归家，两人渐渐走近。

## 二、好感期

- **交警调白班后：** 两人见面渐少。
- **某日：** 交警在她楼下守候；她扔垃圾撞见、仓皇跑回，梳妆打扮后又冲下楼——好感明朗化（仍未表白）。
- **此后：** 窗对窗看花 → 她坦言与母亲闹翻、独居写作 → 约会 → 被交警家人撞见 → 母亲开始催婚。

## 三、定情期

- **大型交通事故日：** 交警忙到天黑；女作家在小区门口等到深夜，送上自制烧烤与手织围巾 → 交警说"我觉得你缺个男朋友" → 定情。

## 四、裂痕期

- **定情后不久：** 交警问"结婚的打算"（本意劝她转行做出版人），被她误听为求婚 → 她以"第一次要给结婚对象"之心同床。
- **此后：** 职业之争（他轻视写作、从不读她的书）→ 冷战。
- **冷战期：** 交警接受家人安排的相亲（未告知她）；她与出版人会面，被交警撞见（误会为被包养的前奏）。
- **冲突日：** 当街撞见她坐在宾利里 → 交警拦车质问、母亲在旁数落 → 她含怒离去（宾利司机实为其父）。

## 五、决裂期

- **冲突当夜或次日清晨：** 她由父亲接回父母家（本地富豪的豪宅小区），拉黑交警、不告而别。
- **冲突后第2-3日：** 交警发现她公寓灯不亮、联系不上，问邻居得知已搬走。
- **其后：** 交警查交警系统得豪宅住址 → 拦"宾利车主"质问 → 被女作家母亲掌掴 → 身世真相大白（她随母姓、与父不似）。

## 六、结局期

- **其后：** 交警家登门道歉 → 女作家母亲冷脸拒亲 → 不欢而散 → 女作家被禁足。
- **禁足期：** 男闺蜜（两家世交、幼时常住她家、留学归国）登门陪伴 → 爆发表白 → 女作家震惊（误以为他是同性恋）、赶走他。
- **结局：** 母女对话——"是人都知道这男的喜欢你" → 女作家开始自我审视，开放收束。
